# 密码校验规格

函数签名：`check_password(password, username)`，返回该密码违反的规则编号列表；列表为空表示密码合格。

- R1：密码长度至少 10 个字符。
- R2：密码长度最多 64 个字符。
- R3：至少包含一个大写英文字母（A-Z）。
- R4：至少包含一个数字（0-9）。
- R5：不得包含用户名，比较时不区分大小写；用户名为空字符串时跳过此规则。
- R6：不得包含任何空白字符（空格、制表符、换行等）。
- R7：返回的规则编号按编号数字升序排列，每个编号最多出现一次。
- R8：当 password 为 None 时抛出 TypeError。
