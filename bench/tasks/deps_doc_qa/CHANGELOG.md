# 更新日志

格式：每个版本一节，最新的在最上面。“未发布”一节中的内容尚未进入任何版本。

## 未发布

### 新增
- 计划引入 `httpx` 替代 `requests`（尚未合入）。

## 2.10.0 - 2026-05-02

### 新增
- 新增依赖 `rich`，用于彩色输出进度。
- `quillsync push` 支持 `--dry-run`。

### 修复
- 修复 Windows 下路径大小写导致的重复上传。

## 2.9.3 - 2026-03-18

### 修复
- 修复断点续传在空文件上的崩溃。

## 2.9.0 - 2026-01-07

### 破坏性变更
- 最低 Python 版本从 3.8 提升到 3.10。
- 配置文件键 `bucket_url` 改名为 `endpoint`。

### 移除
- 移除依赖 `simplejson`，改用标准库 `json`。

## 2.1.4 - 2025-08-21

### 修复
- 上传超时从 10 秒调整为 30 秒。

## 2.0.0 - 2025-04-30

### 破坏性变更
- 命令 `quillsync sync` 拆分为 `push` 与 `pull`。

### 新增
- 新增依赖 `click` 作为命令行框架，取代 `argparse`。

## 1.12.0 - 2024-11-11

### 新增
- 新增依赖 `pyyaml`，支持 YAML 格式配置。
