# 任务：实现 evaluate

用 Python 实现函数 `evaluate(expr: str) -> int`，计算一个整数算术表达式的值。不能使用 `eval`、`exec`、`compile` 或 `ast`。

## 语法
1. 数字是一个或多个 ASCII 十进制数字（允许前导零，`007` 等于 7）；没有小数、没有科学计数法。
2. 运算符：二元 `+`、`-`、`*`、`/`、`^`，一元 `+`、`-`，以及圆括号 `(`、`)`。
3. 优先级从高到低：括号；`^`；一元 `+`/`-`；`*`、`/`；二元 `+`、`-`。
   - `^` 是乘方，右结合：`2^3^2` 等于 `2^9` 即 512。
   - `^` 比一元负号优先级高：`-2^2` 等于 `-4`，`(-2)^2` 等于 `4`。
   - `^` 的右侧可以带一元运算符：`2^-1` 在语法上合法（但会因为指数为负而报错，见下文）。
   - 一元运算符可以连续出现：`--3` 等于 3，`2*-3` 等于 -6。
   - `*`、`/`、`+`、`-` 都是左结合：`10-4-3` 等于 3，`100/10/5` 等于 2。
4. `/` 是向零取整的整数除法：`7/2` 等于 3，`-7/2` 等于 -3，`7/-2` 等于 -3（注意与 Python 的 `//` 不同）。
5. 记号之间可以有任意空白字符（`str.isspace()` 为真的字符），首尾空白忽略；但两个数字之间不能只隔着空白（`1 2` 非法）。
6. 结果总是 `int`，大整数也要精确计算。

## 异常
- `expr` 不是 `str`：抛出 `TypeError`。
- 除数为 0：抛出 `ZeroDivisionError`。
- 乘方的指数为负数：抛出 `ValueError`（`0^0` 等于 1）。
- 其他任何语法错误抛出 `ValueError`，包括：空串或只有空白、未知字符（含 `.`、字母、全角数字）、括号不配对、`()`、缺少操作数、`**` 之类不存在的运算符。

## 约束
只能导入 Python 标准库中的 `re`、`math`、`typing`、`dataclasses`、`collections`、`functools`、`itertools`、`string`，不得进行任何文件、网络或进程操作。

## 交付
最终答案只包含完整的 Python 源码（一个模块，定义 `evaluate`），不要附加解释。
