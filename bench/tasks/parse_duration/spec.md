# 任务：实现 parse_duration

用 Python 实现函数 `parse_duration(text: str) -> int`，把时长字符串解析为总秒数。

## 规则
1. 合法单位只有 `h`（小时）、`m`（分钟）、`s`（秒），每个单位前面是一个非负十进制整数，例如 `1h30m`、`45s`、`2h`、`0s`。
2. 各段之间可以有任意空格，首尾空格忽略，例如 ` 1h 5m 3s ` 合法。
3. 每个单位最多出现一次，且必须按 h、m、s 的顺序出现（`30m1h` 非法，`1h1h` 非法）。
4. 单位区分大小写；`1H` 非法。
5. 以下情况抛出 `ValueError`：空字符串或只有空格、未知单位、缺少数字（如 `h`）、缺少单位（如 `10`）、负数或小数（如 `-1s`、`1.5h`）、重复或乱序的单位、数字与单位之间有空格（如 `1 h`）。
6. 参数不是 `str` 时抛出 `TypeError`。
7. 只能使用 Python 标准库中的 `re`，不得进行任何文件、网络或进程操作。

## 交付
最终答案只包含完整的 Python 源码（一个模块，定义 `parse_duration`），不要附加解释。
