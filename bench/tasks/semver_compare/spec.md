# 任务：实现 compare_versions

用 Python 实现函数 `compare_versions(a: str, b: str) -> int`，按语义化版本 2.0.0 的优先级规则比较两个版本号：`a` 低于 `b` 返回 `-1`，相等返回 `0`，高于返回 `1`（必须是 `int`）。

## 版本号格式
版本号形如 `主.次.修订[-预发布][+构建]`，例如 `1.4.2`、`1.0.0-rc.1`、`2.0.0-beta.2+exp.sha.5114f85`。

1. 主、次、修订都是十进制非负整数，不允许有前导零（`0` 本身合法，`01` 非法）。
2. 预发布部分写在 `-` 之后，由一个或多个用 `.` 分隔的标识符组成；标识符非空，只能包含 ASCII 字母、数字和 `-`；纯数字的标识符不允许有前导零（`0a` 不是纯数字，合法）。
3. 构建部分写在 `+` 之后，由一个或多个用 `.` 分隔的非空标识符组成，字符集同上，但允许前导零。
4. 整个字符串必须完全符合上述格式：不允许前缀 `v`、首尾空白、换行或多余的段。

## 比较规则
1. 先按主、次、修订依次比较数值大小（`1.10.0` 高于 `1.9.0`）。
2. 三者相同时，没有预发布部分的版本高于有预发布部分的版本（`1.0.0` 高于 `1.0.0-rc.1`）。
3. 两者都有预发布部分时，从左到右逐个比较标识符：
   - 两个都是纯数字：按数值比较；
   - 两个都不是纯数字：按 ASCII 字符串顺序比较；
   - 纯数字的标识符低于非纯数字的标识符；
   - 所有对应标识符都相同时，标识符较少的一方较低。
4. 构建部分不参与比较（`1.0.0+a` 与 `1.0.0+b` 相等）。

例如：`1.0.0-alpha < 1.0.0-alpha.1 < 1.0.0-alpha.beta < 1.0.0-beta < 1.0.0-beta.2 < 1.0.0-beta.11 < 1.0.0-rc.1 < 1.0.0`。

## 异常
- 任一参数不是 `str`：抛出 `TypeError`。
- 任一参数格式不合法：抛出 `ValueError`。

## 约束
只能导入 Python 标准库中的 `re`、`math`、`typing`、`dataclasses`、`collections`、`functools`、`itertools`、`string`，不得进行任何文件、网络或进程操作。

## 交付
最终答案只包含完整的 Python 源码（一个模块，定义 `compare_versions`），不要附加解释。
